# Architecture Decision Records

Significant decisions for this project are recorded here, one per file, using the format described in [ADR 0001](0001-record-architecture-decisions.md).

- **Naming:** use `NNNN-short-title.md`, with the next free number. Start from [`template.md`](template.md).
- **Statuses:** `Proposed` → `Accepted` → (`Deprecated` | `Superseded by NNNN`).
- **Accepted ADRs are immutable.** To change a decision, write a new ADR and mark the old one as superseded. Fixing typos or adding links is fine.
